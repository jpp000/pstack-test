# #08 — Minha conta: perfil e endereços (UI)

**Objetivo:** cliente edita perfil e gerencia endereços pela interface.

**Specs:** [05-frontend](../specs/05-frontend.md), [01-accounts](../specs/01-accounts.md)

## Tarefas

- [ ] Página `/account` com formulário de perfil.
- [ ] Lista de endereços com padrão destacado; criar, editar, marcar padrão e apagar (com confirmação).
- [ ] Formulário de endereço reutilizável (será usado também no checkout, #11), com máscara de CEP.
- [ ] Estados de carregamento, erro e vazio.
- [ ] Testes de componente.

## Aceite

- Fluxo completo de endereços funciona contra a API real e a UI reflete o padrão após cada ação sem recarregar.
- O formulário de endereço pode ser usado fora da página de conta (é apresentação pura).
